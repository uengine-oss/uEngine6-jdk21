# SDS +200 시연 실행기 소스

2026-10-08 적용본의 실행 스크립트 보관 경로입니다. 이 폴더는 독립 실행 패키지가 아닙니다.
실제 사용 경로는 SDS 전달 패키지의 `docker` 폴더입니다. 변경한 스크립트를 그 위치에 반영하세요.
`corebank-web-nginx.conf`는 해당 패키지의 `docker/corebank-web/nginx.conf`에 반영합니다.
RPA override의 설정은 기존 plus200 Compose의 rpa-agent 설정에 병합하거나 override로 사용합니다.

- 히트맵·KPI를 먼저 전체 작업영역에 열고 기존6개 업무창을 3열2행으로 앞에 배치.
- 별도 브라우저 프로필과 기존 Windows 사용자 전용 암호화 로그인 파일 사용.
- 모두닫기는 설정에 등록된 시연 프로필만 종료하며 업무 데이터/서버는 보존.
- 최신 process-service 업데이트 TAR 필수. 이미지 ID와 실행 JAR SHA256이 다르면 중단.
- frontend 업데이트 TAR는 기본 이미지 로드 후 적용. 관리자 상세는 기존10초 자동조회 로직 사용.
- 정상DMN복원은 추심 조건을 `> purchaseLimit`으로 복원. 예상하지 않은 규칙은 변경하지 않음.

인증 XML, 환경변수, Docker 이미지 TAR, 로그, DB 백업 및 영상은 이 경로에 넣지 않습니다.
검증기의 이미지/JAR 식별값은 현재 PC에서 확인한 적용본입니다. 승인 실행본 변경 시 함께 갱신하세요.

검증: 관리자9005에서 약10초 간격 instance/status/variables/worklist 조회 HTTP200,
KPI·히트맵 화면 표시, 프로세스 이미지/JAR 식별값 확인, 실행기 구문검사.
제한: 실제8창 동시겹침순서 및 업무완료 후 관리자 상태전이 재검증은 미완료.
멀티인스턴스 한건완료 격리 버그를 해결됐다고 판정하지 않습니다.
